В порту грузовые операции обсуждают со стивидорами, агентом и представителями груза, обычно на английском.

| English | Русский |
| --- | --- |
| loading / discharging | погрузка / выгрузка |
| cargo hold / hatch cover | трюм / крышка люка |
| stowage plan | грузовой план |
| lashing | крепление груза |
| draft survey | драфт-сюрвей, определение массы груза по осадке |
| bill of lading | коносамент |
| dangerous goods | опасные грузы |
| crane / derrick | кран / грузовая стрела |
| tally | счёт груза |
| damage report | акт о повреждении |
| trim / list | дифферент / крен |
| ballast operations | балластные операции |

## Пример

"Loading will start at hold number two. Please confirm the stowage plan." — Погрузка начнётся с трюма номер два. Подтвердите грузовой план.

## Проверь себя

1. Что такое bill of lading? Ответ: коносамент, документ на груз.
2. Как по-английски «крен»? Ответ: list.
