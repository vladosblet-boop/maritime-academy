На судне много данных в таблицах и графиках: таблицы приливов, таблица девиации, диаграммы остойчивости, кривые расхода топлива. Умение быстро их читать экономит время и снижает ошибки.

## Таблицы

Найдите строку и столбец, на пересечении которых нужное значение. Если точного значения нет, применяют интерполяцию.

## Линейная интерполяция

Значение между двумя соседними строками находят пропорционально.

Пример: в таблице девиации для курса 090° δ = +2°, для 120° δ = +5°. Для курса 100°:
δ = 2 + (5 − 2) × (100 − 90) / (120 − 90) = 2 + 3 × 10/30 = 3°.

## Графики

- По горизонтальной оси обычно откладывают аргумент: время, курс, осадку.
- По вертикальной — величину: высоту прилива, расход, плечо остойчивости.
- Значение читают, проводя вертикаль от аргумента до кривой, затем горизонталь до оси.

## Частые ошибки

- Перепутать единицы на осях.
- Взять значение из соседней строки без интерполяции.
- Прочитать не ту кривую на графике с несколькими линиями.

## Проверь себя

1. При 0 ч прилив 1,0 м, при 2 ч — 2,0 м. Сколько при 1 ч по линейной интерполяции? Ответ: 1,5 м.
2. Для курса 090° δ = 0°, для 180° δ = +6°. Какая δ для 120°? Ответ: +2°.

Проверка по учебнику ещё не проводилась. Приливы меняются нелинейно: для точных расчётов используйте правила из таблиц приливов.
