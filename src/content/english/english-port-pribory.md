## Навигационные приборы

| English | Русский |
| --- | --- |
| gyro compass / magnetic compass | гирокомпас / магнитный компас |
| radar / ARPA | радар / АРПА |
| echo sounder | эхолот |
| speed log | лаг |
| autopilot | авторулевой |
| chart / ENC | карта / электронная навигационная карта |
| alarm | тревога, сигнализация |
| malfunction / out of order | неисправность / не работает |

Пример: "Gyro compass is out of order, steering by magnetic compass." — Гирокомпас неисправен, правим по магнитному.

## Общение с портом

| English | Русский |
| --- | --- |
| ETA (estimated time of arrival) | расчётное время прибытия |
| berth | причал |
| anchorage | якорная стоянка |
| pilot boarding position | место посадки лоцмана |
| VTS (Vessel Traffic Service) | служба управления движением судов |
| clearance | оформление, разрешение |

Пример: "My ETA at pilot station is 14:30 UTC." — Моё расчётное время прибытия к лоцманской станции 14:30 UTC.

## Судовые объявления

- "Attention all crew. This is a drill. This is a drill." — Внимание всему экипажу. Это учебная тревога.
- "Fire, fire, fire. Fire in the engine room." — Пожар в машинном отделении.
- "All crew muster at muster station." — Всему экипажу собраться на месте сбора.

## Проверь себя

1. Что означает ETA? Ответ: расчётное время прибытия.
2. Как сказать «не работает»? Ответ: out of order.
