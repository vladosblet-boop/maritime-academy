Названия частей судна на английском нужны в документах, на вахте и при работе с иностранными экипажами.

| English | Русский |
| --- | --- |
| hull | корпус |
| keel | киль |
| deck | палуба |
| main deck | главная палуба |
| superstructure | надстройка |
| bridge | мостик |
| engine room | машинное отделение |
| cargo hold | грузовой трюм |
| ballast tank | балластный танк |
| rudder | руль |
| propeller | гребной винт |
| anchor | якорь |
| bollard | кнехт или береговая тумба |
| fire hydrant | пожарный гидрант |

## Пример

The ballast tank is pumped out. — Балластный танк откачивается.

## Проверь себя

1. Как по-английски «руль»? Ответ: rudder.
2. Как по-английски «машинное отделение»? Ответ: engine room.
