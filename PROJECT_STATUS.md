# Статус проекта: Maritime Academy

Личная образовательная платформа по судовождению. Работает локально, без сервера и внешних сервисов.

## Итог на сейчас

Всё, что перечислено в ТЗ, реализовано. Финальная проверка пройдена (см. ниже).

- **Статьи:** 179 в 17 разделах (16 разделов ТЗ и «Основы»).
- **Тесты:** 17 тем, 54 вопроса.
- **Словарь:** 56 терминов с английскими эквивалентами.
- **Тренажёры:** 12 (список ниже) и 5 калькуляторов.
- **Учебные маршруты:** 3, уровни 1–2.

## Что работает

- **Главная:** уровень подготовки по реальному прогрессу, счётчики, полоса прогресса, следующий урок по учебным маршрутам, избранное, последние тесты, недавно открытые, быстрый поиск, плитки разделов. Для нового пользователя показывается нулевое состояние.
- **Навигация:** боковое меню на компьютере, сворачиваемое меню на телефоне, хлебные крошки, переходы к соседним статьям, связанные темы.
- **Статья:** отметка «пройдено», закладка, статус, «Проверь себя», источники для сверки. Пункты вида «[ ]» становятся отмечаемыми чек-листами.
- **Поиск** по заголовкам, разделам и тексту. **Словарь** с поиском по русским и английским названиям и фильтром по категориям.
- **Тесты:** проверка после ответа на все вопросы, объяснения, история попыток, повтор неверных.
- **Калькуляторы:** узлы и км/ч, мили и км, время перехода и прибытие, градусы и минуты, расход топлива (учебный).
- **Тренажёры:** плавучесть, координаты, COLREG, остойчивость (GM), учебная карта с путевыми точками, движение судна с течением, ситуационные задачи, метеорология, навигационные приборы, морской английский (карточки и тест), схема судна (сбоку, сверху, сечение), навигационный мостик (10 приборов).
- **Мои данные** (/data/): что сохранено, дневная цель, экспорт в файл, восстановление из файла, сброс с подтверждением, данные целиком. Предупреждение о потере данных без резервной копии.
- **Мой прогресс** (/progress/), **Учебные маршруты** (/routes/), **Мой путь к профессии** (статья с 23 отмечаемыми пунктами).

## Финальная проверка (2026-10-26)

- `npm run check`: 179 статей, 620 связей между статьями, битых 0; 208 страниц, 7240 внутренних ссылок, битых 0, пустых страниц 0.
- Консоль браузера: 0 ошибок на 15 страницах всех типов.
- Мобильная версия 375×812: горизонтальной прокрутки нет на главной, статьях с таблицами, тренажёрах, мостике, калькуляторах, «Моих данных», словаре.
- Экспорт, сброс и импорт проверены полным циклом: экспорт → сброс → нулевое состояние главной → импорт → данные восстановлены. Испорченный файл отклоняется и не стирает данные.
- Исправлено при проверке: в сборке оставались 8 устаревших страниц разделов из первой версии (теперь `npm run build` очищает `_site`), следующий урок брался не по маршрутам, уровень подготовки был статичным текстом, у страниц разделов не было названия во вкладке.

## Что важно знать

- **Тексты не сверены с источниками.** 174 статьи написаны по памяти. Статус «готова» значит «написана», а не «проверена». Номера правил МППСС-72, требования конвенций, правила знаков поправок и формулы стоит сверить с учебником и официальными текстами.
- **Морские происшествия:** 5 разборов по отчётам MAIB (Islay Trader, Danio, Ruyter, Hamburg, BBC Marmara) сверены с официальными страницами расследований на gov.uk. Полные PDF не прочитаны.
- **Данные только в браузере** (localStorage, ключ `maritime.progress.v1`). При очистке браузера без резервной копии они пропадут.
- **Модели упрощённые:** тренажёры остойчивости, движения и плавучести — учебные, не инженерные расчёты.
- Формулы записаны текстом, KaTeX не подключён. Источники в поле `sources` — условные ключи, файла `sources.json` нет.

## Решения

- Технология — Eleventy, а не React и Vite: ТЗ разрешает не переписывать работающий проект.
- Приватность: без регистрации, аналитики, рекламы, сервера и внешних сервисов.
- Цены, проходные баллы, зарплаты и конкретные экзамены не указываются.

## Как запустить

```
npm install
npm start       # сайт на http://localhost:8080
npm run build   # чистая сборка в _site/
npm run check   # проверка связей, заголовков и всех ссылок сайта
```

## Структура

```
src/
  index.njk, catalog.njk, section.njk, search.njk, progress.njk, mydata.njk, routes.njk
  glossary.njk, tests.njk, calculators.njk, trainers.njk, schema.njk, bridge.njk
  *.json.njk                        данные для клиента (поиск, тесты, словарь, маршруты)
  _includes/base.njk, article.njk
  _data/sections.json, glossary.json, quizzes.json, routes.json
  content/<раздел>/*.md             статьи; раздел задаётся полем section
  css/style.css, js/app.js
tests/check-links.js, check-site.js
```

## Возможные следующие шаги

1. Сверка статей с источниками по разделам, начиная с МППСС-72 и навигации, с отметкой «проверена» и датой.
2. Тесты к темам, у которых их пока нет.
3. Учебный маршрут третьего уровня.
4. Подключение KaTeX для формул.

## Инструкции для продолжения

1. Прочитать этот файл и CONTENT_PLAN.md.
2. Перед сборкой запускать `npm run check`.
3. После изменений проверять страницы в браузере.
4. Не отмечать статью «проверенной» без сверки с источником.
