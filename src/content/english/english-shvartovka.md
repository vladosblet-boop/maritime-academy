При швартовке мостик, палуба и порт общаются короткими командами. Ошибка в слове может привести к травме, поэтому команды нужно знать точно.

| English | Русский |
| --- | --- |
| head line | носовой швартов |
| stern line | кормовой швартов |
| spring line | шпринг |
| breast line | прижимной (поперечный) швартов |
| let go | отдать |
| heave in / heave up | выбирать |
| slack away | травить |
| hold on | держать |
| make fast | закрепить |
| fender | кранец |
| tug | буксир |
| pilot on board | лоцман на борту |

## Пример

"Forward station, send the head line ashore." — Бак, подайте носовой на берег.

"Let go stern line." — Отдать кормовой.

## Безопасность

Перед командой «heave in» убедитесь, что люди отошли из зоны троса. Команды подтверждают голосом или по рации.

## Проверь себя

1. Что означает slack away? Ответ: травить.
2. Как по-английски «шпринг»? Ответ: spring line.
