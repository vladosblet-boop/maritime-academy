Метеопрогнозы и предупреждения NAVTEX приходят на английском, поэтому термины погоды нужно знать на память.

| English | Русский |
| --- | --- |
| wind | ветер |
| gale | шторм (сильный ветер) |
| gust | порыв ветра |
| swell | зыбь |
| sea state | состояние моря |
| fog | туман |
| visibility good / moderate / poor | видимость хорошая / умеренная / плохая |
| rain / showers | дождь / ливни |
| thunderstorm | гроза |
| low / depression | циклон, область низкого давления |
| high / anticyclone | антициклон |
| cold front / warm front | холодный / тёплый фронт |
| pressure falling / rising | давление падает / растёт |
| icing | обледенение |

## Пример

Wind north-westerly 6, gusts 8. Visibility poor in fog. — Ветер северо-западный 6 баллов, порывы до 8. Видимость плохая в тумане.

Направление ветра указывают по тому, откуда он дует: north-westerly — с северо-запада.

## Проверь себя

1. Что означает gale? Ответ: шторм, сильный ветер.
2. Откуда дует ветер south-easterly? Ответ: с юго-востока.
